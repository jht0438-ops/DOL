# OpenDART 재무제표 기반 영업레버리지도(DOL) 분석

공개 재무제표의 매출액과 영업이익 변화를 이용해 **추정 영업레버리지도(DOL)**를 계산하고, 매출 변동에 대한 영업이익의 민감도를 의사결정 관점에서 해석하는 Streamlit 도구입니다.

## 개발 배경

외부 공시 손익계산서는 일반적으로 다음 구조로 표시됩니다.

```text
매출액 - 매출원가 - 판매비와관리비 = 영업이익
```

하지만 매출원가와 판매비와관리비에는 고정비와 변동비가 함께 포함되어 있어, 공개 재무제표만으로는 공헌이익을 이용한 이론적 DOL을 정확하게 계산하기 어렵습니다.

이에 본 도구는 OpenDART에서 매출액과 영업이익을 불러와 다음 식으로 재무제표 기반 추정 DOL을 계산합니다.

```text
추정 DOL = 영업이익 변화율 ÷ 매출액 변화율
```

예를 들어 매출액이 10% 증가하고 영업이익이 30% 증가했다면 추정 DOL은 3입니다. 이는 해당 기간의 실적에서 매출액이 1% 변화할 때 영업이익이 약 3% 변화했다는 의미입니다.

## 주요 기능

- 기업명 또는 종목코드로 OpenDART 기업 검색
- 연결재무제표 우선 적용, 미제공 시 별도재무제표 자동 전환
- 당기·전기 매출액과 영업이익 자동 수집
- 매출액 변화율, 영업이익 변화율 및 추정 DOL 계산
- DOL 구간에 따른 영업이익 민감도 자동 해석
- 결과가 높거나 낮게 계산된 이유를 한 문장으로 설명
- 성장기·침체기 관점의 의사결정 포인트 제공
- 음수 DOL, 흑자·적자 전환, 미미한 매출 변화 등 예외 처리
- 분석 신뢰도 `양호 / 주의 / 해석 어려움` 표시

## DOL 해석

DOL이 높을수록 매출 변화에 영업이익이 크게 반응한 것으로 해석할 수 있습니다. 매출 성장기에는 이익 확대 효과가 크지만, 매출 감소 시 영업이익도 더 큰 폭으로 줄어들 수 있습니다.

DOL이 낮을수록 매출 변화에 대한 영업이익의 반응이 상대적으로 작습니다. 매출 감소 시 이익 안정성이 높을 수 있지만, 매출 증가에 따른 이익 확대 효과도 제한될 수 있습니다.

DOL의 높고 낮음은 절대적인 우열을 뜻하지 않습니다. 또한 본 도구의 값은 기업 내부 관리회계 자료로 계산한 구조적 DOL이 아니라, 공개 재무제표의 두 기간 실적을 바탕으로 계산한 추정치입니다.

## 로컬 실행 방법

### 1. 패키지 설치

```bash
pip install -r requirements.txt
```

### 2. API 키 설정

`.streamlit/secrets.toml.example`을 복사하여 `.streamlit/secrets.toml` 파일을 만들고, 본인의 OpenDART API 키를 입력합니다.

```toml
DART_API_KEY = "본인의_OpenDART_API_KEY"
```

`secrets.toml`은 `.gitignore`에 포함되어 있어 GitHub에 업로드되지 않습니다.

### 3. 실행

```bash
streamlit run app.py
```

## Streamlit Community Cloud 배포

1. 이 프로젝트를 GitHub 저장소에 업로드합니다.
2. Streamlit Community Cloud에서 해당 저장소와 `app.py`를 선택합니다.
3. 앱 설정의 **Secrets**에 다음 내용을 입력합니다.

```toml
DART_API_KEY = "본인의_OpenDART_API_KEY"
```

4. 배포를 실행합니다.

> 실제 API 키가 들어간 `.streamlit/secrets.toml` 파일은 GitHub에 올리지 마세요.

## 분석 유의사항

다음 경우에는 일반적인 DOL 해석이 어렵거나 결과가 과도하게 계산될 수 있습니다.

- 전기 또는 당기 영업이익이 0에 가깝거나 적자인 경우
- 영업적자에서 흑자로, 또는 흑자에서 적자로 전환된 경우
- 매출액 변화율이 매우 작은 경우
- 매출액과 영업이익이 서로 반대 방향으로 움직인 경우
- DOL 절댓값이 지나치게 큰 경우

도구는 이러한 상황을 자동으로 감지하여 `주의` 또는 `해석 어려움`으로 표시합니다.
